# customer-segmentation-kmeans

Kaggle-ориентированный ML-проект для сегментации клиентов методом K-Means с одним основным ноутбуком.

## Запуск проекта

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Поместите исходные данные в папку `data/`.
3. Откройте `notebooks/solution.ipynb` и выполняйте ячейки по порядку.
4. Сохраните артефакты (графики, метрики, сабмишн) в `results/`.

## Project Structure

```text
customer-segmentation-kmeans/
├── data/                 # Исходные и промежуточные данные
├── notebooks/
│   └── solution.ipynb    # Основной ноутбук с полным пайплайном
├── results/              # Графики, метрики, submission-файлы
├── src/
│   ├── __init__.py
│   └── utils.py          # Заготовка для будущего рефакторинга из ноутбука
├── requirements.txt
└── README.md
```

Почему один основной ноутбук:
- для Kaggle это самый удобный формат воспроизводимого end-to-end решения;
- весь экспериментальный поток (EDA → фичи → обучение → оценка → submission) виден в одном месте;
- по мере роста проекта код можно постепенно выносить в `src/` без потери скорости итераций.
