# customer-segmentation-kmeans
# Сегментация клиентов с помощью K-Means

## Описание проекта

Данный проект демонстрирует сегментацию клиентов с использованием алгоритма кластеризации K-Means.

Датасет содержит информацию о клиентах страховой компании, включая:

- возраст;
- уровень дохода;
- размер страхового покрытия;
- размер страховой премии.

Цель проекта — разделить клиентов на группы со схожими характеристиками.

---

## Используемые технологии

- Python
- pandas
- scikit-learn
- matplotlib
- numpy

---

## Этапы работы проекта

Проект состоит из следующих этапов:

1. Загрузка и анализ данных
2. Выбор числовых признаков
3. Масштабирование данных с помощью `StandardScaler`
4. Подбор количества кластеров методом локтя (Elbow Method)
5. Кластеризация клиентов с помощью K-Means
6. Снижение размерности данных с помощью PCA
7. Визуализация результатов

---

## Используемые признаки

Для кластеризации использовались следующие числовые признаки:

- Age
- Income Level
- Coverage Amount
- Premium Amount

---

## Метод локтя (Elbow Method)

Для подбора оптимального количества кластеров использовался метод локтя.

По графику зависимости inertia от количества кластеров было видно, что после `k = 5` уменьшение inertia становится менее значительным.

Поэтому для итоговой модели было выбрано:

```python
KMeans(n_clusters=5)
```

## PCA-визуализация

Так как данные содержат несколько измерений, для визуализации использовался метод PCA (Principal Component Analysis).

PCA позволяет уменьшить размерность пространства признаков до двух компонент с минимальной потерей информации.

Это позволяет отобразить кластеры на двумерном графике.
